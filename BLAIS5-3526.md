## Tasks

Implement the rules mentioned below (these can likely be given to an agent to implement as they look suspiciously like they may be intended that way )

- [x] In the toml use PEP 621 \[project\] metadata, adding only fields needed by the project. For a distributable package, include the required package metadata and build configuration.

	- Keep test files out of the measured production coverage, add explicit omission or source configuration only when needed for this repository.
