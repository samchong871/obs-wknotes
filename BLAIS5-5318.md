- Cal found that agents may be updating themselves
	- When environments shut down, they remove the existing agent
	- On restart, they install the agent version in the config file (which atm is the older version except ben2)
	- At some point, they seem to auto-update to the newest agent version from MS
		- Which then gets removed on shutdown
		- And replaced with the (potentially) older version specified on startup
	- Less noticeable on sandboxes (daily shutdown overnight)
		- So if newer version autoinstalled during day, removed on restart
	- But for formal environments (weekly scheduled)
